# joplin-obsidian-roundtrip
Lossless bidirectional converter between Joplin raw exports and Obsidian vaults. Preserves folder icons, attachments, empty placeholders, and YAML metadata byte-for-byte. Filesystem-aware sanitization for NTFS, APFS, exFAT, and cloud sync. Built for users who switch between apps and refuse to lose structure on the way back.
